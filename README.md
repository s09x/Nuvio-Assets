# Nuvio Assets

Custom artwork for Nuvio.

## Year collections

`collections/by-year` contains nine distinct film covers. Labels run from 2026 through 2020, followed by 2015 (2015–2019) and 2010 (2010–2014).

## Discover collections

`collections/discover/de` contains six covers and their six hover variants.

## Decade collections

`collections/by-decade` contains six decade designs from the 2000s through the 1950s, each with its cover and hover variant.

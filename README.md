# Nuvio Assets

Custom artwork for Nuvio collections.

The `collections/by-year` directory contains nine 1280 × 720 WebP covers. The visible labels run from 2026 through 2020, followed by 2015 (2015–2019) and 2010 (2010–2014). Each cover uses a different film image from its represented period and follows the existing collection thumbnail design.

Artwork was edited with `gpt-image-2.5-sunburst` using the existing covers as style references and separate film backdrops as image references. The adjacent manifest records periods, source backdrops, dimensions, and file hashes.
